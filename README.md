# Distance Calculator

## Description
This program calculates the distance between two points using their x and y coordinates

## How to Run
1. Open the program
2. Run the program
3. Enter the required coordinates

## Input Needed
X1- enter X1 coordinates
Y1- enter Y1 coordinates
X2- enter X2 coordinates
Y2- enter Y2 coordinates

## Sample Output
The distance between two points is 7.07
